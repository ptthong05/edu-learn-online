# Cài đặt Website

## Tổng quan

Tùy chỉnh thông tin và giao diện tổng thể của website EduLearn.

## Truy cập

`Admin Dashboard → Cài đặt Website`

## Các tùy chọn cài đặt

### Thông tin cơ bản

| Trường | Mô tả |
|--------|-------|
| Tên website | Tên hiển thị trên Header và Tab trình duyệt |
| Slogan | Khẩu hiệu hiển thị dưới tên website |
| Logo | Upload ảnh logo (JPG, PNG, SVG) |
| Màu chủ đạo | Màu sắc chính của website (màu tên website) |
| Màu phụ | Màu sắc phụ (màu slogan) |

### Logo & Branding

- **Có logo**: Hiển thị ảnh đã upload trong Header và Footer
- **Không có logo**: Hệ thống tự tạo khung chữ viết tắt (2 ký tự đầu tên website) trên nền xanh
- **Xóa logo**: Nhấn nút "Xóa logo" để về chế độ chữ viết tắt

### Thông tin liên hệ

| Trường | Mô tả |
|--------|-------|
| Email liên hệ | Email hiển thị ở trang Liên hệ và Footer |
| Số điện thoại | Số điện thoại hỗ trợ |
| Địa chỉ | Địa chỉ công ty |
| Facebook URL | Link fanpage Facebook |
| YouTube URL | Link kênh YouTube |

### SEO

| Trường | Mô tả |
|--------|-------|
| Meta title | Tiêu đề trang (SEO) |
| Meta description | Mô tả ngắn (SEO) |
| Google Analytics ID | Mã theo dõi GA4 |

## Lưu thay đổi

Sau khi chỉnh sửa, nhấn **Lưu thay đổi**. Hệ thống hiện thông báo xanh lá ở góc phải màn hình xác nhận thành công.

> Thay đổi có hiệu lực ngay lập tức trên toàn bộ website.

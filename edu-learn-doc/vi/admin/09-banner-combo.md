# Banner & Combo khóa học

## Banner trang chủ

### Tổng quan
Banner là phần hiển thị nổi bật đầu trang chủ, dùng để thu hút người dùng.

### Truy cập
`Admin Dashboard → Banner trang chủ`

### Chỉnh sửa Banner

| Trường | Mô tả |
|--------|-------|
| Dòng tiêu đề 1 | Dòng chữ đầu tiên của tiêu đề |
| Dòng tiêu đề 2 | Dòng chữ thứ 2 (hiển thị màu vàng gradient) |
| Dòng tiêu đề 3 | Dòng chữ thứ 3 (màu vàng gradient) |
| Mô tả | Đoạn text phụ bên dưới tiêu đề |
| Badge text | Nhãn nhỏ phía trên tiêu đề (VD: "Nền tảng học trực tuyến hàng đầu") |
| Ảnh minh họa | Hình ảnh bên phải banner |
| Nút CTA chính | Text nút kêu gọi hành động chính |
| Nút CTA phụ | Text nút kêu gọi hành động phụ |

## Combo khóa học

### Tổng quan
Combo là gói nhiều khóa học bán cùng nhau với giá ưu đãi hơn mua lẻ.

### Truy cập
`Admin Dashboard → Combo`

### Tạo Combo mới

| Trường | Bắt buộc | Mô tả |
|--------|----------|-------|
| Tên Combo | ✅ | Tên gói combo |
| Mô tả | ❌ | Mô tả nội dung combo |
| Khóa học bao gồm | ✅ | Chọn nhiều khóa học từ danh sách |
| Giá combo | ✅ | Giá bán combo (thường thấp hơn tổng giá lẻ) |
| Giá gốc hiển thị | ❌ | Giá gốc để tính % tiết kiệm |
| Thumbnail | ❌ | Ảnh đại diện combo |
| Trạng thái | ✅ | `active` / `inactive` |

### Hiển thị

Combo được hiển thị trong section **"Combo Tiết kiệm"** trên trang chủ và trang `/combos`.

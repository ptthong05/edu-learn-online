# Lộ Trình Phát Triển Tính Năng (Feature Roadmap)

> **Dự án:** EduLearn Online Platform  
> **Thư mục:** `edu-learn-doc/discovery/`  

---

## 1. Giai đoạn 1: Ra mắt Nền tảng Core (v1.0 - Hiện tại)

- [x] Quản lý Khóa học, bài học qua Drive, Gói Combo khóa học.
- [x] Mua khóa học & Thanh toán chuyển khoản kèm ảnh minh chứng.
- [x] Phân quyền người dùng (User, Admin, Manager, Staff, Affiliate).
- [x] Hệ thống Cộng tác viên Affiliate (Mã ref, Theo dõi hoa hồng, Yêu cầu rút tiền).
- [x] Quản lý Mã giảm giá (Coupon), Banner trang chủ & Bài viết Blog.
- [x] Tích hợp gửi mail tự động qua Gmail SMTP (Nodemailer).

---

## 2. Giai đoạn 2: Nâng cấp Trải nghiệm & Tự động hóa (v1.1 - Q4 2026)

- [ ] **Tích hợp Cổng thanh toán Tự động:** Tích hợp SeABank / VietQR API / Momo / ZaloPay tự động xác thực số tiền chuyển khoản qua nội dung (Webhook).
- [ ] **Chứng chỉ hoàn thành khóa học:** Tự động cấp file PDF Chứng chỉ học viên khi hoàn thành 100% bài học.
- [ ] **Đánh giá & Thảo luận:** Thảo luận dưới từng bài học video giữa học viên và giảng viên.

---

## 3. Giai đoạn 3: Mở rộng Hệ sinh thái & Mobile App (v2.0 - 2027)

- [ ] **Mobile App:** Phát triển ứng dụng iOS/Android bằng React Native.
- [ ] **AI Assistant Bot:** Trợ lý AI giải đáp thắc mắc nội dung bài học trực tuyến cho học viên.
- [ ] **Livestream / Subscriptions:** Hỗ trợ mô hình đăng ký hội viên trả phí hàng tháng (Subscription Model).

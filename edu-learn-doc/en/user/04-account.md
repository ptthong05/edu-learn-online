# Account Management

## Access

`/tai-khoan` or click **Avatar → Account**

## Account Tabs

### Tab: Personal Information

| Field | Description |
|-------|-------------|
| Full Name | Display name |
| Email | Login email (cannot be changed) |
| Phone Number | Contact phone number |
| Avatar | Profile picture |
| Address | Residential address |
| Bio | Short personal introduction |

### Tab: Change Password

1. Enter your **Current Password**
2. Enter a **New Password** (minimum 6 characters)
3. Confirm the new password
4. Click **Change Password**

### Tab: My Courses

- List of all purchased / enrolled courses
- Progress for each course
- **Continue Learning** / **Start Now** button

### Tab: Order History

- List of all placed orders
- Order details: products, price, status
- Filter by status: pending / completed / cancelled

### Tab: Affiliate Info (if Affiliate)

- Personal referral code
- Total commission earned
- Withdrawal history
- Request a new withdrawal

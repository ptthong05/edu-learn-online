# Purchasing a Course

## Finding Courses

### Course Listing Page (`/courses`)
- Search by **keywords**
- Filter by **category**
- Filter by **price** (free / paid)
- Sort by **newest**, **most popular**, **price**

## Purchase Process

### Step 1: Add to Cart
- Click **Add to Cart** on the course detail page
- Or click **Buy Now** to go directly to checkout

### Step 2: Review Cart (`/cart`)
- Review courses in your cart
- Remove unwanted courses
- Enter a **coupon code** if available

### Step 3: Checkout (`/checkout`)
- Confirm order details
- Select **payment method**
- Complete payment following the instructions
- Upload proof of payment (for bank transfers)

### Step 4: Confirmation
- A confirmation page is shown after successful order
- A confirmation email is sent to your inbox

### Step 5: Access Course
After Admin confirms payment:
- Course appears in **My Courses**
- Start learning immediately!

## Applying Coupon Codes

1. Go to **Cart** or **Checkout**
2. Enter the code in the **Coupon Code** field
3. Click **Apply**
4. Price updates automatically

# Order Management

## Overview

Track and manage all purchase transactions on the EduLearn platform.

## Access

`Admin Dashboard → Orders`

## Order List

| Column | Description |
|--------|-------------|
| Order ID | Unique order identifier |
| Buyer | Buyer name & email |
| Products | Courses / Combos purchased |
| Total | Amount paid |
| Method | Payment method used |
| Status | `pending` / `completed` / `cancelled` |
| Created At | Order date & time |

## Order Statuses

| Status | Meaning |
|--------|---------|
| `pending` | Awaiting payment confirmation |
| `completed` | Payment confirmed, course access granted |
| `cancelled` | Order has been cancelled |

## Viewing Order Details

- Buyer information
- List of products in the order
- Applied coupon code (if any)
- Payment information
- Order status history

## Search & Filter

- Search by **order ID** or **buyer email**
- Filter by **status**
- Filter by **date range** (start date – end date)
- Filter by **payment method**

## Revenue Statistics

Charts showing:
- **Daily / Weekly / Monthly revenue**
- **Top selling courses**
- **Orders by status**

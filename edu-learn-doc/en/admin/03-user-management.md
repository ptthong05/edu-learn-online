# User Management

## Overview

The user management module allows admins to view, search, suspend/restore accounts, and review transaction history for each user.

## Access

`Admin Dashboard → Users`

## User List

The table displays all accounts with the following columns:

| Column | Description |
|--------|-------------|
| Avatar | Profile picture |
| Full Name | User full name |
| Email | Registered email address |
| Role | `admin` / `user` |
| Status | `active` / `banned` |
| Joined Date | Registration date |
| Actions | View details, Ban/Unban |

## Viewing User Details

Displayed information:
- **Personal Info**: Name, email, phone, address
- **Purchase History**: List of orders and purchased courses
- **Learning Progress**: Enrolled courses and completion percentage
- **Affiliate Info**: Stats if user is an affiliate

## Banning / Unbanning Accounts

- **Ban**: User cannot log in; sees a "banned" notification
- **Unban**: Restores normal access

## Search & Filter

- Search by **email** or **full name**
- Filter by **role** (`admin` / `user`)
- Filter by **status** (`active` / `banned`)

## Pagination

Displays 20 users per page by default. Navigate using the pagination controls at the bottom of the table.

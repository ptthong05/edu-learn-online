# Site Settings

## Overview

Customize the general information and appearance of the EduLearn website.

## Access

`Admin Dashboard → Site Settings`

## Settings Options

### Basic Information

| Field | Description |
|-------|-------------|
| Website Name | Name shown in Header and browser tab |
| Slogan | Tagline shown below the website name |
| Logo | Upload logo image (JPG, PNG, SVG) |
| Primary Color | Main brand color (website name color) |
| Secondary Color | Secondary brand color (slogan color) |

### Logo & Branding

- **With logo**: Displays uploaded image in Header and Footer
- **No logo**: System auto-generates initials (first 2 characters of website name) on a blue background
- **Delete logo**: Click "Delete Logo" button to revert to initials mode

### Contact Information

| Field | Description |
|-------|-------------|
| Contact Email | Email displayed on Contact page and Footer |
| Phone Number | Support phone number |
| Address | Company address |
| Facebook URL | Fanpage link |
| YouTube URL | Channel link |

## Saving Changes

After editing, click **Save Changes**. A green toast notification appears in the bottom-right corner confirming success.

> Changes take effect immediately across the entire website.

# Banners & Course Combos

## Homepage Banner

### Overview
The banner is the prominent section at the top of the homepage, used to attract users.

### Access
`Admin Dashboard → Home Banner`

### Editing the Banner

| Field | Description |
|-------|-------------|
| Title Line 1 | First line of the heading |
| Title Line 2 | Second line (shown in yellow gradient) |
| Title Line 3 | Third line (yellow gradient) |
| Description | Supporting text below the heading |
| Badge Text | Small label above title (e.g. "#1 Online Learning Platform") |
| Hero Image | Illustration image on the right side |
| Primary CTA | Main call-to-action button text |
| Secondary CTA | Secondary call-to-action button text |

## Course Combos

### Overview
Combos are bundled packages of multiple courses sold together at a lower price than buying individually.

### Access
`Admin Dashboard → Combos`

### Creating a New Combo

| Field | Required | Description |
|-------|----------|-------------|
| Combo Name | ✅ | Bundle package name |
| Description | ❌ | Bundle content description |
| Included Courses | ✅ | Select multiple courses from list |
| Combo Price | ✅ | Bundle sale price |
| Original Price | ❌ | Original price for showing savings % |
| Thumbnail | ❌ | Combo cover image |
| Status | ✅ | `active` / `inactive` |

### Display

Combos are shown in the **"Value Combos"** section on the homepage and at `/combos`.

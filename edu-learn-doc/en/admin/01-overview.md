# Admin Dashboard Overview

## Introduction

The Admin Dashboard is the central management interface for EduLearn, giving administrators full control over the platform.

## Accessing Admin

1. Navigate to `/admin`
2. Enter your admin email and password
3. You will be redirected to the Dashboard

> **Note**: Only accounts with the `admin` role can access this area.

## Dashboard Structure

### Sidebar Navigation
- **Dashboard** – Key statistics overview
- **Courses** – Manage all courses
- **Categories** – Manage course categories
- **Combos** – Course bundle packages
- **Users** – User account management
- **Orders** – Transaction history
- **Coupons** – Discount code management
- **Affiliate** – Affiliate marketing system
- **Blog** – Blog post management
- **Payment Methods** – Payment configuration
- **Banners** – Homepage banner management
- **Website Content** – CMS content
- **Site Settings** – General configuration

### KPI Statistics Cards

| Metric | Description |
|--------|-------------|
| Total Revenue | Total from all completed orders |
| Total Orders | Number of orders in period |
| New Users | Newly registered accounts |
| Active Courses | Courses currently on sale |

## User Roles

| Role | Permissions |
|------|-------------|
| `admin` | Full system administration |
| `user` | Standard user – buy and learn courses |

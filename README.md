# EduLearn – Documentation

> Tài liệu chính thức của nền tảng học trực tuyến **EduLearn**.

## Giới thiệu

EduLearn là nền tảng học trực tuyến qua drive toàn diện, hỗ trợ quản lý khóa học, người dùng, thanh toán, affiliate marketing, blog, và nhiều tính năng khác.
